# Hey Bara

Android 음성 AI 비서 프로젝트 (Kotlin Native)

## Project Info

- Language: Kotlin
- Platform: Android (Android Studio)
- Target: Galaxy S25 Edge (Snapdragon 8 Elite, 12GB RAM)
- Distribution: Personal sideloading (APK)

## Key Components

- Wake Word: Porcupine ("헤이 바라")
- STT: Sherpa-ONNX Zipformer Korean
- NLP: Koog Agent + Gemma 3n (on-device) / Gemini API (cloud)
- TTS: Supertonic 2
- Actions: Call, SMS, KakaoTalk, Calendar, Tasks, Notifications

## Conventions

- Korean language for user-facing strings and TTS responses
- English for code (variable names, comments, docs)
- Follow Android/Kotlin coding conventions
